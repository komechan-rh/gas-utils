# 定期実行の手順書（Claude Code routine 用）

毎日の routine が読み込む指示書です。routine 側には「このファイルに従う」旨・対象スプレッドシートID・実行スケジュールだけを設定し、手順の本体はここで管理します。

## 前提（routine の環境）

- 環境変数 `AMAZON_STORAGE_STATE_B64`: `scripts/export-session.mjs` で書き出した Cookie
- ネットワーク許可: `amazon.co.jp` / `*.amazon.co.jp` / `*.media-amazon.com` / `*.ssl-images-amazon.com`
- Google Sheets コネクタ（備品購入リストの読み書き）
- 対象スプレッドシートIDは routine のプロンプトで渡す（リポジトリには書かない）

## 厳守事項

- **注文の確定・レジへの遷移・「今すぐ買う」は行わない。** カートに入れるところまでで止める（確定は人が Amazon アプリで行う暫定運用）
- `scripts/add-to-cart.mjs` のガードレール（通信遮断）ブロックを編集しない。スクリプトで解決できない画面差異は、その注文を「要確認」として書き戻し、手作業で操作しない
- `AMAZON_STORAGE_STATE_B64` の値、スクリーンショット、ページ本文を表示・外部送信しない。書き戻し・報告に氏名・住所・支払い情報を書かない
- シートは見出し名で列を特定し、以下で指定した列以外を書き換えない

## 手順

1. Google Sheets コネクタで、指定スプレッドシートの「備品購入リスト」を1行目（見出し）から全行読む
2. `ステータス` が `未処理` の行を集める。0件なら「未処理なし」と報告して終了
3. 各行から `{ receiptId: 受付ID, asin: ASIN, quantity: 数量(数値), priceCap: 価格上限(数値、空なら null) }` を作り、scratchpad に `orders.json` として保存する。ASIN が空の行は実行対象から外し、その行は手順5で `失敗`（備考「ASINが空です」）にする
4. `node amazon-business-order/scripts/add-to-cart.mjs <orders.json> <scratchpad>` を実行する（playwright は `require('playwright')` で解決できる）。標準出力の1行1注文の JSON を結果とする
5. 結果があった行だけ、受付IDで行を特定して次の列を書き戻す（結果が無い行は `未処理` のまま残す。ログイン切れで中断した場合など）
   - `ステータス`: 結果の status（`カート追加済` / `要確認` / `失敗`）
   - `処理日時`: 結果の processedAt をそのまま書く（スクリプトが出した日本時間。自分で時刻を組み立てたり丸めたりしない）
   - `備考`: 結果の note
   - `通知日時`・`注文番号`・`ご請求額`・`注文日時` は触らない（通知は GAS が、確定後の情報は人が扱う）
   - 書き込みは見出しから求めた列のセルを1つずつ A1 形式（例: `備品購入リスト!H2`）で指定して行う。行全体や連続範囲をまとめて書き込まない（列がずれて別の列を上書きする事故を防ぐため）
6. 書き戻した内容を読み直し、手順1で読んだ内容と比べて、指定の3列以外（特に `価格上限`・`ASIN`・`数量`）が変わっていないことを確認する。変わっていたら元の値に戻し、その旨を報告する
7. 最終報告: 処理件数と、受付IDごとの status・note（個人情報を含めない）

LINE への結果通知は、GAS（`manager-line-notifications` の `notifyOrderResultsToLine`、毎時）が `通知日時` の空いた結果行を拾って行う。routine から LINE には送らない。
